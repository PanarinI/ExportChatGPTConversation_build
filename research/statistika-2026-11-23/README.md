# Статистика использования ExportGPT — снимок 23.11.2026

Вопрос автора (23.11): «посмотри статистику… мы вроде недавно ставили новые счётчики».
Источник — GA4 ресурса 540507186 (события расширения + приветственная страница), сервис-аккаунт, $0. Скрипт `snyat.py`,
сырьё — `raw/`. Страница магазина — снята 23.11.

## Что нашлось

1. **1.3.0 в магазине с 18.11** (страница CWS: Version 1.3.0, Updated November 18, 2026). Пользователей — 1 000,
   оценка 4,8 по 18 голосам, 51 язык.
2. **Счётчик форматов слепой.** С 1.2.9–1.3.0 каждый `export_completed` несёт `format` (pdf · word · md · claude · gdocs ·
   obsidian · notion — `PRIVACY.md`), но в ресурсе заведены измерения только `choice`, `layout`, `mode`, `reason` и метрики
   `found`, `read` (`raw/metadata.json`). Без заведённого измерения отчёты GA4 параметр не показывают, а задним числом его
   не достать: данные пойдут с момента, когда измерение заведут. Дни с 18.11 для разреза по формату потеряны.
   Не заведён и `excluded` (сколько блоков сняли при выборе блоков).
3. **Неделя 16–22.11 — больше всего людей с конца сентября:** экспорт сделали 124 человека (недели с 28.09: 95–116),
   экспортов 384.
4. **Выбор блоков берут чаще:** 16–22.11 — 30 экспортов у 14 человек; в прошлые недели с 28.09 — 3–20 у 3–11. Совпадает с
   новым меню 18.11 («What goes in · Pick blocks…»). 🔶 числа малые; 12 из 30 — один человек 20.11.
5. **Отказов меньше:** 1–22.11 — 36 на 1 103 попытки (3,3 %); 1–22.10 — 66 на 1 376 (4,8 %). С 1.11 главная причина —
   `network` (29 из 37: запрос до нашего сервера не дошёл). Ошибок сервера `http_500` с 13.11 нет; `too_large` — 3 за
   19–23.11, по одному-два в неделю бывало и с августа.
6. **Людей больше, экспортов на человека меньше:** 1–22.10 — 1 310 экспортов у 267 человек (4,9 на человека);
   1–22.11 — 1 067 у 307 (3,5). Почему — ⬜.
7. **Приветственная страница:** первых визитов 248 за 1–22.11 (за те же дни октября — 285); кнопку Export на ней (ведёт в
   ChatGPT, событие `wp_export_click`) нажали 57 человек, 107 раз.
8. **Старая вёрстка ChatGPT (classic) почти ушла:** с 10.11 — 4 экспорта из 734.
9. **`export_partial` — ни одного за ноябрь**, как и ждали 15.11 (на новой странице ChatGPT окно не встаёт).

## Чего этот снимок не знает

- Какой формат выбирают люди — до тех пор, пока не заведено измерение `format` (п. 2).
- Версию у человека: номера версии в событиях нет. Доля обновившихся до 1.3.0 — ⬜ (Chrome обновляет сам, обычно за сутки).
- «Людей» GA4 считает по случайному `client_id` расширения: переустановка — новый человек. Недели между собой сравнимы,
  с числом пользователей магазина — нет (`app-studio/analytics/REVISION.md`).
- Тесты автора с дев-сборки сюда не попадают (дев молчит); с копии из магазина — попадают.

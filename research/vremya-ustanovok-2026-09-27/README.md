# Когда ставят ExportGPT — дни недели и часы по странам (27.09.2026)

**Вопрос автора.** Около 1 000 установок: видны ли временные паттерны по странам первой десятки —
например, «в среду вечером в США ставят значимо чаще»?

**Ответ.** Такого паттерна нет. Значимо видно одно — **время суток по местным часам**: ставят днём и
вечером, у каждой страны свой пик. Дни недели внутри стран не различаются сверх случайности. Единственная
«выпирающая» ячейка «день × время» (США, понедельник 12–18) — всплеск одного дня, а не недельный ритм.

## Границы

- **Мощность.** При n ≈ 140 (США) день недели стал бы значимым с поправкой, только если бы был примерно
  вдвое выше среднего; при n ≈ 50–70 — ещё сильнее. Эффекты ±30 % этими данными не видны: «не нашли» ≠
  «нет». Для таких нужно на порядок больше установок на страну.
- **Ночь.** Проверка «части суток против равномерного» слабая по замыслу — ночью спят. Содержательна
  не значимость, а где пик.
- **Окно.** GA4 с 09.06 (раньше метки на странице приветствия не было). Май и начало июня — только стор.

## Побочная находка: «США» стора ≠ США по IP 🧮

В одних и тех же днях стор записал в США **214** установок, GA4 по IP — **119**; при этом Китай 30 → 50,
Япония 26 → 46, а всего 831 против 807 — почти вровень. То есть около сотни установок, которые стор
считает американскими, пришли с IP других стран. Стор, видимо, берёт регион аккаунта, GA4 — место
по IP (тем, кто за VPN, он тоже может ошибиться). Разбор доли удалений 09-17 («держит только США»)
стоял на регионах стора — его «США» выходит смесью.

## Удаления по IP — повтор разбора 09-17 (27.09)

**Точно — нельзя** ⬜: удалений с местом по IP не записывает никто. На странице удаления
(`exportgpt-pages/uninstall.html`) нет кода аналитики — только Google-форма; стор отдаёт удаления по
региону аккаунта; события расширения идут без страны. (Публичная политика при этом пишет, что страница
удаления «uses Google Analytics… to count visits» — расходится с кодом.)

**Граница — можно** 🧮. Окно 09-17 (17.08–15.09): группа «США» стора — 58 установок, 9 удалений
(16 %). По IP из США из них ~28, остальные ~30 — аккаунты США в других странах (Китай по IP 23 против
11 в сторе, Россия 16 против 11, Тайвань 9 против 6). Как 9 удалений делятся между двумя половинами, не
видно, но каждая половина не может иметь больше всех 9: доля у физических США ≤ 9 / 28 ≈ 32 %, у аккаунтов
США за рубежом ≤ 9 / 30 = 30 % — против 52 % у всех остальных (85 / 163). **Мало удаляют обе половины.**
Значит, дело не в физической Америке, а в том, у кого аккаунт с регионом США. Кто они — 🔶 (гипотеза:
опытные пользователи, в т.ч. из Китая, где аккаунт США — обычный способ обойти региональные ограничения).
Оговорки те же, что в 09-17: удаления отстают от установок; GA4 видит ~90 % установок.

**Чтобы получить точно:** поставить на страницу удаления тот же код GA4, что на странице приветствия.
Тогда установки (`first_visit` на приветствии) и удаления (просмотр страницы удаления) будут из одного
источника и с одной страной по IP; через ~30 дней — доля удалений по странам по IP.

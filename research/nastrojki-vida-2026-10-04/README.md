# Настройки вида листа против конкурентов (04.10.2026)

**Вопрос автора.** «Достаточно ли у нас настроек, или наоборот переизбыток, или есть ненужные /
бессмысленные?» Посмотреть, как делают конкуренты.

**Ответ коротко.** Базовый набор рынка у нас есть весь. По числу не перебор: у лидера около 25 настроек,
у нас 15. Недостаёт двух вещей, которые есть у обоих лидеров, — номеров страниц и закладок-оглавления в
боковой панели PDF; обе проверены на нашем сервере и работают. Бессмысленная — одна («Include model
name»); сломанное — два набора умолчаний; путают названия двух пунктов. Оценку у конкурентов делает
верность вывода, а не число настроек.

Тиры: ✅ проверено (код, официальный источник, проба) · 🔶 толкование / сторонний источник · ⬜ неизвестно.

**Два набора умолчаний ✅.** При установке `background.js` пишет `datetime_format: 'date_only'`,
`source_link: true`; кнопка «Reset to defaults» берёт `gptpdfShared.defaultOptions` (`shared.js`):
`'none'` и `false`. Новый человек получает дату и ссылку включёнными, «сброс» их выключает. До 1.1.10
к тому же каждое обновление включало их обратно у выключивших (DECISIONS 10-04).

**Два «theme» ✅ (по тексту окна).** «Color theme» (светлый / тёмный лист) стоит в разделе Output format,
а раздел «Theme» с пунктом «Style» меняет только цвет пузыря вопроса.

**Скрытые ключи** (`q_fg_color`, `q_align`, `q_rounded`, `no_icons`, `q_color_picker`) в окне не
показаны, в коде зашиты значения — наследство PDFCrowd, человеку не видно; чистка кода, не продукта.

**Чем пользуются люди — ⬜.** Настройки не уходят в аналитику; какие из них трогают, мы не знаем.

## 3. Пробы на нашем сервере (04.10, `export-gpt.duckdns.org`, Gotenberg 8.34.0)

Двухстраничный HTML с заголовками h1/h2, `curl` на `/forms/chromium/convert/html`, текст и закладки
вытащены PDFKit.
- **Номера страниц ✅:** файл `footer.html` с `pageNumber` / `totalPages` + `marginBottom=0.6` → внизу
  «1/2», «2/2».
- **Закладки ✅:** `generateDocumentOutline=true` сам по себе — закладок 0; вместе с
  `generateTaggedPdf=true` — есть (19 → 21 КБ). Значит, оглавление можно продублировать в боковой
  панели PDF-читалки без смены сервера.

## 4. Разбор каждой нашей настройки

| Настройка | Вердикт | Почему |
|---|---|---|
| Page size, ориентация, поля, Font size, Color theme, Page breaks, Title, TOC, «только ответы», выбор блоков | **оставить** | базовый набор рынка или наша сильная сторона (оглавление) |
| Single page | оставить, **опустить ниже** | ниша (чтение с экрана), а стоит первой строкой окна — самое заметное место |
| Custom margins | оставить | поля в дюймах — для немногих, но прячутся, пока не выбран Custom; цена внимания ≈ 0 |
| Theme → Style | оставить, **переименовать** в «Question color» и поставить рядом с Color theme; раздел «Theme» убрать | сейчас два «theme» в разных разделах; пункт меняет ровно цвет вопроса — пусть так и называется |
| Creation date | оставить, **переименовать** в «Export date» | это дата выгрузки; лидер различает «создан / обновлён / выгружен» |
| Include model name | **убрать** (решение автора) | показывает модель, выбранную сейчас в переключателе, а не ту, что отвечала; в чате их бывает несколько; работает ли на нынешних страницах — ⬜ |
| Дата и ссылка в шапке у новых | **решение автора**: выключить по умолчанию? | голос 07-21 «не тащите метки расширения сверху»; «Reset» их и так выключает; у лидеров дата — выбор, не умолчание 🔶 |
| Два набора умолчаний | **починить** — один набор | баг ✅ |

**Добавить** (решение автора): номера страниц внизу листа (оба лидера; проба ✅); закладки в боковой
панели вместе с оглавлением (проба ✅, ничего не видно, пока не открыть панель). Шрифт с засечками /
моно — следующая по частоте; без голосов наших людей — не сейчас.

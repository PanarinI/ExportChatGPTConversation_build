## Как делается каждый файл 🧮

- **PDF** — как сейчас: страницу печатает наш сервер.
- **Markdown** — собирается прямо в браузере, из того же собранного чата. ChatGPT сам строит ответы из Markdown, поэтому
  обратный перевод выходит чистым: заголовки, списки, таблицы, код с языком, ссылки, жирный и курсив. Сервер не нужен —
  быстро, и чат не уходит с устройства.
- **Word** — тоже в браузере. Файл .docx — это zip-архив из XML-файлов, его можно написать своим кодом без библиотеки:
  своего кода ≈20 КБ 🧮, готовая библиотека `docx` весит в разы больше 🔶. Внутри: заголовки, абзацы, списки, таблицы,
  код моноширинным шрифтом на сером фоне, ссылки, картинки внутри файла.
- **Что переносится из настроек:**
  - Word: стиль (шрифты), вопросы, бумага и поля, «каждый вопрос с новой страницы», номера страниц, шапка. Тёмного листа
    и «одной длинной страницы» у Word нет.
  - Markdown: вопросы и шапка (название, дата, ссылка на чат, оглавление). Шрифтов и бумаги у текста нет — в окне они
    приглушены, с пояснением.

## Открытые вопросы ⬜ (решённые в 1.2.9-dev — с ✅)

- ✅ Картинки в Markdown — не кладутся, на их месте строка «[Picture]» (DECISIONS 18.11).
- ✅ Шрифты в Word — те, что есть везде: Arial, Georgia, Calibri, Consolas.
- ✅ Вопросы в Markdown — «**You:**» / «**ChatGPT:**» при Bubble, «##» при Heading.
- ✅ Формулы новых ответов — TeX читается обратно из вёрстки KaTeX; в Word — родные формулы.

- **Формулы новых ответов.** ChatGPT хранит их только отрисованными, исходника TeX на странице нет (DECISIONS 16.11).
  В PDF они печатаются как на экране, а в Markdown и Word им нужен исходник. Старые ответы его держат (`data-math-source`).
  Варианты: восстанавливать TeX из отрисовки (для дробей, степеней и корней это выполнимо) или ставить формулу картинкой.
- **Картинки в Markdown.** Внутрь .md картинку не положить. Ссылка на картинку ChatGPT со временем умирает.
  Варианты: архив .zip «чат.md + папка картинок» или картинки прямо в тексте (Obsidian их покажет, GitHub — нет).
- **Шрифты в Word.** Noto и Carlito не стоят на компьютерах. Варианты: вшить их в файл (тяжелее) или назначить шрифты,
  которые есть везде (Calibri, Cambria, Arial).
- **Как подписывать вопросы в Markdown:** `**You:**` или заголовок `### You`.
- Другой путь — брать чат прямо с сервера ChatGPT, с исходным Markdown и TeX (так делают крупные экспортёры). Это новый
  способ чтения и новая строка в Privacy, отдельное решение. В 1.2.9 не входит.

## Меню — варианты макета

Макет: [`maket-formaty.html`](maket-formaty.html), один файл, открывается из Finder. Собирает `maket/sobrat.py` из живого
стенда `tests/blockmode-live-stand.html` — кнопка, лист, окно настроек и «Select to export» там настоящие. Кадры снимает
`maket/snimki.sh` → `dizajn/kadry/2026-11-17-formaty/`.

Общее для всех вариантов:
- «Select all» уходит из меню: это и так делает кнопка Export.
- «AI answers only» переезжает в настройки третьим положением строки Questions: Bubble · Heading · **Hidden**. Лист сразу
  показывает чат без вопросов, строка «Question colour» гаснет.

Сами варианты:
- **A. Формат — выбор в меню.** Три плитки PDF · Word · Markdown выбирают, какой файл даст кнопка Export. Значок на
  кнопке — выбранный файл. Под плитками одна строка подсказки. «Select to export» — одной строкой, второе предложение
  ушло в подсказку при наведении. При Markdown лист в меню становится текстом.
- **B. Каждый формат — своя кнопка.** Строка формата сразу скачивает файл, кнопка Export всегда даёт PDF. Подписи в две
  строки, как сейчас. В режиме выбора блоков понадобятся свои три кнопки: там выгрузка идёт с главной кнопки.
- **C. Три листа.** Формат выбирают по картинке файла: страница PDF, страница Word, текст Markdown. Щелчок по выбранному
  листу открывает настройки. Страницы PDF и Word выглядят одинаково — различает только значок. Меню выше, и при каждом
  открытии рисуются три листа.
- **D. Формат — в настройках.** В меню остаются лист и «Select to export». Формат выбирается в окне настроек, над
  закладками, а подпись под листом называет его («PDF · Chat»). Word не виден тому, кто пришёл за Word.

**Рекомендация Клода — A** 🧮:
- одно нажатие остаётся одним нажатием, файл виден на самой кнопке;
- режим выбора блоков работает с любым форматом без новых кнопок;
- меню той же ширины.
